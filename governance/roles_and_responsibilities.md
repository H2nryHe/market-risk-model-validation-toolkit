# Roles And Responsibilities

This is a single-developer portfolio project. It does not claim organizational
independence, real bank approval authority, or employment experience in an
institutional model-risk-management function.

Project-level independence is simulated through separated responsibilities,
separated code paths, independent reference calculations, distinct evidence
artifacts, and explicit decision records.

## Model Owner / Developer

Responsible for:

- methodology definition
- model implementation
- configuration
- technical documentation
- model changes

The model owner/developer role owns how the model is designed, configured,
implemented, and changed in the project codebase.

## Independent Validation

Responsible for:

- conceptual challenge
- independent/reference implementation
- implementation verification
- challenger comparison
- outcomes analysis
- sensitivity/stability analysis
- findings and recommendations

The independent validation role challenges whether model design, implementation,
outcomes, and limitations are fit for the stated hypothetical intended use.

## Model Risk Governance

Responsible for:

- model inventory
- lifecycle status
- validation status
- findings tracking
- remediation tracking
- monitoring/escalation framework
- validation-decision recordkeeping

The model risk governance role maintains the project-level record of what the
model is, how it is used, what evidence has been reviewed, what findings exist,
and which decision labels are available after validation work is complete.
